# Architecture

`Assets/Editor/ARSolarSystemPhase1Setup.cs` owns idempotent AR scene, plane prefab, info panel, and initial Android player-setting setup. It calls `SolarSystemContentSetup` to create/update procedural material assets and the `SolarSystem.prefab`. `SolarSystemBuilder` creates all bodies, orbit curves, rings, and lights beneath one contents root. Central scientific values live in `PlanetaryData`; `SolarSystemVisualAssets` holds material references. `PlanetaryMotionController` advances registered pivots and axial rotations using `Time.deltaTime`, with one pause state and educational/relative-period modes. `PlanetInteraction` ignores EventSystem UI touches and resolves the closest physics hit to a planet. `PlanetInfoPanel` renders data in the generated TextMeshPro Canvas. Planet maps are deterministic low-resolution procedural illustrations, so the app can run without network access or external image licensing.

`SolarSystemARController` owns horizontal-plane raycasts, AR anchors, and one-model placement/reset. It reports AR Foundation session states to the status UI. `SolarSystemUIManager` wires generated controls to placement, animation, and scale changes. `SolarSystemBuilder.SetScales` changes body diameters from the Sun ratio and orbital distances from a separate metres-per-AU value, updating existing bodies and line renderers without rebuilding. `SolarSystemUserSettings` persists the selected values in PlayerPrefs.

The scene uses Unity's built-in renderer for the simplest stable pipeline in this Unity release. Default mean orbital distances use an independent linear scale of 0.25 metres per AU. The default Sun diameter is 0.10 metres. The UI explicitly explains that the physical-size and distance scales are independent and do not form a complete scale model.

Numerical data source: [NASA GSFC NSSDCA Planetary Fact Sheet (metric)](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) and [fact sheet notes](https://nssdc.gsfc.nasa.gov/planetary/factsheet/planetfact_notes.html). Distances are mean distances/semi-major axes; periods and sidereal rotation definitions follow the notes. Moon counts are the officially confirmed counts in that fact sheet, last updated 18 March 2025, and can change as discoveries are confirmed.
